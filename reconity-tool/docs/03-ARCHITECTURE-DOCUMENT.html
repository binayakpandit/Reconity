System Overview

Reconity is built on a modular microservices architecture designed for scalability, security, and resilience. The platform separates concerns between the client-facing web application, the API gateway, and background processing workers.

🌐

Web Client

React-based SPA with premium UI/UX

⚡

API Gateway

Express.js RESTful API with JWT auth

🔄

Scan Workers

BullMQ-powered async job processing

Data Flow Architecture

🌐 Presentation Layer

React + TypeScript frontend communicates with the API Gateway via HTTPS. All requests are authenticated using JWT tokens stored in localStorage.

⚡ Application Layer

Express.js API Gateway handles business logic, validates requests with Zod, and orchestrates database operations through Prisma ORM.

🔄 Processing Layer

Long-running scans are offloaded to BullMQ workers via Redis queues. Workers execute security tools and persist results to the database.

💾 Data Layer

SQLite (dev) / PostgreSQL (prod) stores users, targets, and scan results. Redis provides high-speed caching and message brokering.
